Гайд :О

1. рядом с .exe файлом создать папки для каждой компании
2. в папках должны быть файлы body.txt, config.txt, employes.txt, them.txt, кодировка UTF-8

3. про файлы
    3.1 в body.txt должен лежать текст письма. все ключи ("company_name", "fio_first", "dolzhnost", "company_name_one", "fio_second", "dolzhnost2", "email", "tel") нельзя менять.
    3.2 в config.txt лежат значения для ключей из предыдущего пункта. Они автоматически подставляются вместо указанных фраз.
    3.3 в employes.txt лежит почта-ФИО каждого из компании, кому нужно отправить
    3.4 в them.txt лежит тема письма
4. F:\img\oleg\output\image.png - пример полного пути к файлу

5. ВАЖНО: в директории с .exe файлом должны лежать только папки компаний, .exe файл не переименовывать
